# CodeAlpha Basic Calculator

## About Project
This is a Basic Calculator developed using C Programming as part of the CodeAlpha Internship.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by Zero Error Handling
- Repeat Calculations
- Exit Option

## Technologies Used
- C Programming
- Visual Studio Code
- GCC Compiler

## How to Run
1. Download calculator.c
2. Open terminal in VS Code.
3. Compile using:

   gcc calculator.c -o calculator

4. Run using:

   .\calculator.exe
